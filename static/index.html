Norwegian Transport

Journey planning, real-time departures, and stop search across all Norwegian public transport. Built for AI agents.

x402 micropayments USDC on Base Entur No API key

Endpoints

Source & freshness

Data from Entur, the Norwegian national transport authority. Free, no API key — Entur asks every caller to send an ET-Client-Name header which we set automatically. Stops cached 7 d, line detail 24 h. Journeys and departures are real-time and never cached.
